Instalace - Windows

Meetily Watcher

Automatický přepis a diarizace schůzek (Whisper + rozpoznání mluvčích) běžící na pozadí. Instalace jedním příkazem. Hledáš Mac verzi? Je tady.

1. Stáhni instalátor a spusť ho (dvojklik)

Jeden soubor, žádné kopírování příkazů.

⬇ Stáhnout Nainstalovat-Meetily.zip

  1. Otevři soubor ze složky Stažené soubory (dvojklik na Nainstalovat-Meetily.zip).
  2. Klikni pravým tlačítkem na soubor uvnitř a vyber Extrahovat vše (Extract All), pak Extrahovat. Otevře se nová složka se souborem Nainstalovat-Meetily.bat.
  3. Poklikej na ten .bat soubor v nově otevřené složce.
  4. Windows se zeptá, jestli si opravdu chceš tenhle soubor spustit ("Neznámý vydavatel" / "Open File - Security Warning") - klikni Spustit / Run. Tohle okno se objeví u úplně každého souboru staženého z internetu, není to specifické pro tenhle instalátor.
  5. Objeví se okno Windows s dotazem na oprávnění správce - klikni Ano.
  6. Otevře se černé okno a hned po něm uvítací okno s instrukcemi - to už tě instalace vede sama krok za krokem.
Nefunguje stažení/rozbalení ZIP souboru (firemní zásady, antivirus)? Použij některou z alternativ níže.

Časté otázky k bezpečnostním varováním

Proč se mi zobrazuje varování, že soubor může poškodit počítač / neznámý vydavatel?
Protože je to skript stažený z internetu a nikdo si ho (zatím) nekoupil digitální podpis, který stojí peníze. Stejné varování by se objevilo u jakéhokoliv jiného skriptu odkudkoliv - neznamená to, že je něco špatně. ZIP formát navíc obchází nejagresivnější variantu tohoto varování v prohlížeči (Chrome/Edge), zůstává jen mírnější potvrzovací okno přímo od Windows při spuštění .bat souboru.

Je bezpečné kliknout na "Spustit i tak" / "Ponechat"?
Ano - obsah instalátoru je veřejně vidět v tomhle repozitáři, nic se neděje skrytě. Pokud si nejsi jistý/á, zeptej se Matyáše, než cokoliv spustíš.

Dostal jsem to přes Slack, ne přes tenhle web - je to jinak?
Ne, princip je stejný. Soubor stažený odkudkoliv z internetu (Slack, e-mail, tahle stránka) dostane od Windows stejné "neznámý vydavatel" varování při prvním spuštění - to je vlastnost Windows, ne konkrétního kanálu.

Alternativa A: Pošli odkaz Claude (vyžadován funkční Claude Code)

Máš spuštěný Claude Code (s přístupem k terminálu na tomhle PC)? Zkopíruj zprávu níže a pošli mu ji přesně tak, jak je - repo obsahuje instrukce, které si Claude sám přečte a instalaci spustí za tebe.

zpráva pro Claude
naklonuj a nainstaluj https://github.com/matyaspolidar-bot/meetily-watcher-installer-windows
Musí to být Claude Code (s reálným přístupem k příkazové řádce) - ne Claude chat v prohlížeči nebo režim "jen klikání na obrazovku". Ty typy relací nemůžou příkazy spouštět a instalace by neproběhla.

Alternativa B: PowerShell ručně

Klávesa Windows → napiš PowerShell → klikni pravým tlačítkem na "Windows PowerShell" → Spustit jako správce. Pak vlož tenhle příkaz (klik pravým tlačítkem, nebo Ctrl+V) a stiskni Enter.

powershell
$b = "$env:TEMP\meetily-bootstrap.ps1"; Invoke-WebRequest -Uri "https://matyaspolidar-bot.github.io/meetily-watcher-installer-windows/install.ps1" -OutFile $b; & $b
Tohle je přesně to samé, co spouští i tlačítko výše - vidíš přesně to samé, co je v install.ps1, nic se neděje skrytě. Schválně to není zkrácené na "jeden řádek s irm | iex" - tenhle běžný tvar u Windows Defenderu občas spustí falešný poplach (ML heuristika na vzorec "stáhni skript a hned ho spusť").

2. Co se bude dít dál (v tomto pořadí)

  1. Windows se může párkrát zeptat na potvrzení UAC okna (instalace Pythonu/ffmpeg/appky) - vždy potvrď.
  2. 3x se otevře prohlížeč na stránce Hugging Face - založení účtu, odsouhlasení licence modelů, vytvoření přístupového tokenu. Appka přesně napíše, co kde kliknout.
  3. Instalace trvá 30-60 minut (stahují se AI modely) - nezavírej okno PowerShellu, dokud nedoběhne.
  4. Na konci se Windows může zeptat na povolení Mikrofon / Nahrávání obrazovky - u obou potvrď.

Něco nejde?

Průběh instalace se ukládá do %USERPROFILE%\whisper-setup\install.log. Napiš Matyášovi a pošli mu tenhle soubor. Příkaz je bezpečné spustit znovu - nic se nerozbije, jen doběhnou kroky, které se ještě nestihly.
